# darkbringer1's Homebrew tap

```sh
brew install --cask darkbringer1/tap/zerre
```

| Cask | What |
| --- | --- |
| [`zerre`](Casks/zerre.rb) | [Zerre](https://zerre.dogukaan.dev), a tiny creature that lives on your Mac's desktop and grows from your workday. Installs `Zerre.app` and the `zerrectl` command. |

Zerre updates itself through Sparkle, so `brew upgrade` skips it unless you pass `--greedy`. The cask is bumped automatically on every Zerre release.
